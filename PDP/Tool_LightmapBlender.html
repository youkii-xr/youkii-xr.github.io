Lightmap Blender

Unity Editor Tool Light Baking Shader

About

  • Complete Day-Night Blending system for Unity, integrated with Day-Night Skybox, Post Processing Volumes, URP Emissive Materials, Baked Lightmaps and custom fog & cloud shaders, to offer comprehensive Time of Day Profiles
  • Used in production of Mandjet
  • Optimized and Tested for standalone VR runtime

Features

  • Visual Timeline Editor
  • Support Addressables for more optimized runtime loading
  • Support Static and Non-Static Meshes
  • Scriptable Object based lighting profiles
  • Configurable day-night states and transition curves
  • Editor Tools to switch time-of-day states easily for debugging

Motivation

  • Built to overcome the limitations of Unity 6 Lighting Scenarios which only switch lightbake profiles with no support to skybox, emission values, post processing
