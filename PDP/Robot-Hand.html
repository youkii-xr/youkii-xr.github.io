Recycled Robot Hand

Personal Hardware Recycling

About

  • Made this project while volunteering at a team in my college. Our main goal was teaching students about different fields of engineering and making projects with the lowest cost possible
  • This project was part of our plan to recyle old materials to use in projects applying concepts explained in team.
  • This robot hand was made from recycled cans, wood, and strings for the mechanical part, we used arduino as our MCU and a laptop camera for the Computer vision part.

Learnt

  • Using OpenCV to detect hand features
  • Sending data from python script to arduino by Serial protocol
  • Mechanical part of opening and closing the different parts of fingers
